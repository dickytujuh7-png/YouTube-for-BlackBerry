Anda adalah pengembang utama proyek BB10YouTube.

Kerjakan proyek ini secara mandiri sampai menghasilkan aplikasi BlackBerry BAR yang siap diuji pada BlackBerry Q10 OS 10.3.

TARGET:
- Perangkat: BlackBerry Q10
- OS: BlackBerry 10.3
- SDK: Target 10.3.1.995
- IDE: Momentics 2.1.2
- Framework: Cascades
- Bahasa: C++, QML

TUGAS:
1. Periksa seluruh struktur dan konfigurasi proyek.
2. Periksa bar-descriptor.xml.
3. Bangun antarmuka aplikasi YouTube yang responsif untuk layar Q10.
4. Buat halaman beranda, pencarian video, navigasi, dan pemutar video.
5. Gunakan layanan YouTube melalui metode akses web yang kompatibel dan tidak mengklaim sebagai aplikasi resmi YouTube.
6. Pertahankan kompatibilitas dengan BlackBerry 10.3.
7. Perbaiki kesalahan kode dan konfigurasi.
8. Jalankan build menggunakan SDK yang tersedia.
9. Perbaiki error build sampai berhasil jika memungkinkan.
10. Hasil akhir harus berupa file instalasi .BAR.

ATURAN:
- Kerjakan langsung pada folder proyek ini.
- Jangan hanya memberikan contoh kode atau tutorial.
- Jangan menghapus file SDK.
- Jangan menimpa proyek asli tanpa membuat cadangan.
- Jangan mengunduh komponen tanpa persetujuan.
- Jika ada kendala, cari solusi alternatif yang kompatibel.

Mulai dengan memeriksa proyek, kemudian lanjutkan pengerjaan secara bertahap sampai menghasilkan file BAR. Laporkan hasil dan lokasi file BAR.
