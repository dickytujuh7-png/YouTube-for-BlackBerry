# FeatherBrowser build status

- Target: BlackBerry Q10 Android Runtime, Android API 18+, ARMv7.
- Client: native Android Java app using OkHttp WebSocket.
- Features: connect to Android-hosted Feather server, URL/search, JPEG frames, tap, wheel scroll, back, reload.
- Latest APK build: successful GitHub Actions run; artifact `FeatherBrowser-Q10-ARMv7`.
- APK: compiled and signed as a debug APK. Physical Q10 installation and runtime are not yet tested.
- Server: experimental Termux/Chromium adaptation. Must be tested on the Android phone before claiming compatibility.
